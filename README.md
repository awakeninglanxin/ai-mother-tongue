## 三、核心结论与诚实边界

1. **EEQT 的不可替代性从第 3 级（单轨迹化）才开始**：Lindblad 生成元与分段确定性过程（PDP）一一对应，使量子主方程获得严格的单次运行解释；量子—经典控制接口需要 EEQT 的完全正映射半群语义。
2. **「五比特为基就不需要纠错」是倒置的**：`[[5,1,3]]` 是最小完美**量子纠错码**（抗任意两比特擦除），HaPPY 六腿张量即是它。正解是「不需**额外**纠错电路，纠错已嵌入几何」。纠错码保逻辑信息 ≠ 消除退相干——两者是独立工程。
3. **EEQT 不是算力层**：它是接口 / 单轨迹语义层，与 GPU+CUDA 是异构互补而非同台竞速。
4. **ε 抹平实验的结论**：收缩比 ρ(ε)=(1−ε)/(1+ε) 的对数衰减率给出 Γ(ε)=0.5·artanh(ε)。F1 单调抹平 PASS、F2 两端极限 PASS；F3 的 ε→Γ 物理标度需真实实验能谱标定，保持 OPEN。
5. **几何律 ρ*=θ/6 是好经验律但不是定理**：独立膝点检验均值偏差 0.023、最大 0.075（四面体）。`law.json` 原表由同一假设机械生成，不可用于自证。
6. **SEG 冷源（2026-11-23 观测修正）**：「必须真空 + 多层绝热」是「若真有 4K」的假言条件，不是 Searl 机现状；**Searl 机表面不凝结霜** ⟹ 按第 9 条测温判据 4K 不成立，冷源现阶段只剩 227K 实测档、对 SNSPD 无用。13W@4K 只是真空 + MLI 下的理论上限；供电 / 供光仍不成立。

所有未证实项一律标 OPEN，不硬凑结论。
